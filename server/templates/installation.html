Installation Guide

Creating The Bookmark

There are 2 ways to make the bookmark:

Method 1

  1. Drag this button into your bookmarks bar

    If you're on Firefox, right click on the button and then click "bookmark link."

Method 2

  1. Make a new bookmark (can be any page you're gonna change it anyways)
  2. Edit that Bookmark and change the URL to the following 
    javascript: fetch("https://cdn.jsdelivr.net/gh/ading2210/edpuzzle-answers@latest/script.js").then(r => r.text()).then(r => eval(r));
  3. Save the bookmark

Content Security Policy (CSP) Extension

Installing the CSP Extension

Due to recent changes by Edpuzzle, you need to disable the CSP on edpuzzle.com for the script to work. To bypass it, install one of these browser extensions:

  • For Chrome/Edge/Opera/Brave: Disable Content-Security-Policy
  • For Firefox: Disable CSP for a minute

Using the script

Usage on regular Edpuzzles

  1. Go to any Edpuzzle assignment
  2. Make sure the url follows looks like this: https://edpuzzle.com/assignments/{id}/watch
  3. Click on the CSP extension and make sure it's on (it should change colors from grey to pink)
  4. Reload the page
  5. Click on the bookmarklet to run the script

Usage on Edpuzzles in Canvas

  1. Go to the assignment on Canvas and make sure the link looks like this: https://k12.instructure.com/courses/{id}/assignments/{id}
  2. Click on the bookmarklet. The script should open the Edpuzzle assignment in a new tab
  3. Click on the CSP extension and make sure it's on (it should change colors from grey to pink)
  4. Reload the page
  5. Re-run the bookmarklet to launch the full script
  6. If that doesn't work, make sure you allow popups on both Edpuzzle and Canvas
